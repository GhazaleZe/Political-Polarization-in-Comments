# Political-Polarization-in-Tweets
Codes for a research project in Information retrieval topic

There are different steps for re-run this project if you want to start from scratch start from step 1 otherwise you can go to step 3.
All dataset is added.

# First Step: Cleaning US Election 2020 
Code of This Section is in Polarity_Clean_Save.py
use the files of Kaggle US 2020 Election Tweets (https://www.kaggle.com/datasets/manchunhui/us-election-2020-tweets/data?select=hashtag_joebiden.csv) "hashtag_joebiden" and "hashtag_donaldtrump" in separate files.
The output of this step is "biden_US_cleaned.csv" and "trump_US_cleaned.csv"

# Second Step: civility label prediction

Code of this section is in predictionClass.ipynb

It's a notebook, you can run it cell by cell. 

# Third Step: Polarization and Results

Code of this section is in 2 file separately for each candidate.

biden_final.ipynb For candidate biden 
trump_final.ipynb For candidate biden

It's a notebook, you can run it cell by cell.
